Why We Built Turbo: From an Accident to a Solution

A real accident in our city inspired our 4-student team to take action and save lives.

📍 Stadium Street, Kafr El Sheikh, Egypt • شارع الاستاد، كفر الشيخ

A teenager we know had a car accident because he didn't know the road sign. We felt heartbroken, but we didn't just feel sad—we decided to use our coding skills to solve the problem!

“Driving books are boring and kids don't read them. Video games make learning fast, active, and fun!”

Driving lessons start at age 18, but teenagers cross busy roads, ride bikes, and walk near fast cars every single day. They need road knowledge right now!

How We Built It • لغات وأطر البرمجة

How We Built It: Python & Pygame

We built the whole game from scratch using Python and free tools.

🐍 Python 3 Core
Core Language
  • Clean, easy language that helped 15-year-old students learn fast
  • Organized into 7 clean files for menus, race, shop, and quiz
  • Runs fast and smoothly on simple school computers
  • Works 100% offline in classrooms—no internet needed
🎮 Pygame Framework
Game Framework
  • Powers the 60 FPS car movement, roads, and collisions
  • Draws our player car, opposing cars, and gold coins
  • Handles smooth screen drawing and keyboard controls
  • Plays music and crash sounds with zero delay
📦 PyInstaller Standalone
Distribution
  • Compiles all Python code and pictures into a single Turpo.exe (60 MB)
  • Opens immediately with a double-click on Windows
  • No need to install Python or anything on school computers
  • Perfect for students and teachers in any school lab
📐 Game Math & Logic
Built-in Stdlib
  • 6 lane positions so cars stay perfectly on the road
  • Simple box collision math to detect car crashes
  • Random traffic and coin positions to make every race fresh
  • Speed formulas that increase gradually as points go up
🌐
Presentation Web Stack: This competition presentation itself is built with vanilla HTML5, CSS3, and JavaScript—running 100% offline!
