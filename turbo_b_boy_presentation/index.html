Origin & Mission • قصة البداية والمشكلة

From a Real Accident to a Life-Saving Game

What happened on Stadium Street in Kafr El Sheikh inspired four 15-year-old students to turn Python code into road safety.

📍 Stadium Street, Kafr El Sheikh, Egypt • شارع الاستاد، كفر الشيخ

The spark for Turbo Game started after a traffic accident happened on Stadium Street in our city of Kafr El Sheikh. A teenager our age was injured because they didn't know traffic signs. We felt heartbroken, but we decided to take action using our programming skills.

“Instead of just worrying about dangerous roads, we coded a game to teach road signs before teenagers ever drive.”

Driving lessons start at age 18, but teenagers cross busy roads, ride bikes, and walk near fast cars every single day. Traditional 100-page booklets are boring—video games teach quick reflexes and memory!

1

Driving Lessons Start Too Late

Official driving schools only accept 18+. Teenagers need road awareness right now.

2

Textbooks Don't Work

Kids don't read traffic manuals. Games turn rules into exciting muscle memory.

3

Our Goal: Turbo Game

A 100% free educational game running on any simple school PC or laptop.

Feature Deep Dive: Coins & Health System

How coins reward knowledge and how the 3-heart system teaches kids careful, defensive driving.

💰 Coins Economy

Economy Rule
🛣️
Highway Coin Spawning
Gold coins spawn randomly across open lanes as you drive. Steer into them to grab +1 coin.

Audio Chime Feedback
Collecting a coin immediately plays a rewarding audio chime and animates the HUD coin counter.

Quiz Coin Multiplier
Players earn +1 coin for every correct traffic sign question answered in the quiz screen.

❤️ 3-Hearts Health System

Safety Rule
3️⃣
3 Initial Hearts
Every run begins with 3 hearts in the bottom-left corner. Just like real life, safety must be protected!
💥
Crash Deducts 1 Heart
Colliding with any oncoming traffic vehicle immediately deducts 1 heart and triggers crash audio.
🛡️
1-Second Invincible Flashing Safe-Mode
After a hit, your car flashes transparent for 1 second so you have time to steer out of double danger.
🚫
Zero Health = Educational Game Over
No magic hearts on the road. When 3 hearts run out, Game Over launches with a road sign lesson.

How We Built It • لغات وأطر البرمجة

Frameworks & Libraries: Real Python Code!

Student-engineered from the ground up using the best open-source Python game development tools.

🐍 Python 3.12 Core
Core Language
  • Clean, beginner-friendly syntax empowering 15-year-old student developers
  • Pure modular architecture: Game.py, play_page.py, store.py, questions_page.py
  • Fast state machine switching seamlessly between all 7 game screens
  • Lightweight execution with zero heavy backend or web browser overhead
🎮 Pygame & Pygame Zero
Game Framework
  • High-performance 60 FPS main game loop with update() and draw() hooks
  • Actor sprite management for player racer, oncoming cars, and coin animations
  • Hardware-accelerated 2D surface rendering via SDL library
  • pygame.mixer low-latency multi-channel audio playback and mute control
📦 PyInstaller Standalone
Distribution
  • Compiles Python code, Pygame libraries, and media assets into Turpo.exe
  • Compact 60 MB file size that runs instantly on double-click
  • No Python installation or command line required on school computer labs
  • Works 100% offline on any standard Windows 10 or 11 laptop or PC
📐 Math & Physics Libraries
Built-in Stdlib
  • 6-lane lateral coordinate clamping and boundary collision checking
  • colliderect bounding-box mathematics for pixel-precise vehicle hitboxes
  • random module: Dynamic AI traffic spawning, lane distribution & coin timers
  • resource_path() helper for dynamic file loading inside bundled executable
🌐
Presentation Web Stack: This competition presentation itself is built with vanilla HTML5, CSS3, and modern ES6 JavaScript running offline in any browser.
